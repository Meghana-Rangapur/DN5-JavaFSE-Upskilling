Ex 19 — Sass Customization

Customizing Bootstrap with Sass

Ex 19.1 — Setup Bootstrap 5 with Sass via npm
# 1. Install Bootstrap and Sass
npm init -y
npm install bootstrap @popperjs/core
npm install --save-dev sass

# 2. Project structure
scss/
  ├── _variables.scss // your overrides
  └── main.scss // entry point

# 3. Compile
npx sass scss/main.scss dist/css/main.css --watch
Ex 19.2 — _variables.scss — override primary color & border-radius
// _variables.scss — Override BEFORE importing Bootstrap

$primary: #1a3a5c; // Civic navy replaces Bootstrap blue
$secondary: #c8952a; // Civic gold
$success: #3b5e3a; // Civic moss green
$border-radius: 10px; // Softer corners globally
$border-radius-lg: 16px; // Larger radius for cards/modals
$font-family-base: 'DM Sans', sans-serif;
$headings-font-family: 'Playfair Display', serif;

// main.scss — import variables THEN Bootstrap
@import 'variables';
@import '../../node_modules/bootstrap/scss/bootstrap';
Result: After recompiling, every Bootstrap component — buttons, alerts, cards, badges — automatically uses your custom colors and border radii. No need to override individual CSS classes.
Ex 1.2 & 2.1 — Bootstrap Files

Bootstrap Directory Structure

css/

bootstrap.min.css — compiled minified stylesheet.
bootstrap.css — readable source.
bootstrap-grid.css — grid-only build.
bootstrap-reboot.css — reset-only build.
bootstrap-utilities.css — utilities only.

js/

bootstrap.bundle.min.js — JS + Popper bundled (use this).
bootstrap.min.js — Bootstrap JS only (Popper separate).
bootstrap.esm.js — ES module version.
Each plugin also available standalone.

icons/

Separate package: bootstrap-icons.
Installed via CDN or npm.
Over 2,000 SVG icons.
Used as <i class="bi bi-*">.
Font and SVG sprite variants available.
